# Game Flow UI

이 폴더는 사망 후 관전 대상 전환과 리스폰 카메라 복구, 로비 직업 선택과 서버 요청을 보여줍니다.

## 처리 흐름

### 사망 관전

`사망 지점 앵커·현재 플레이어 목록 구성 → 입력 지연 후 관전 전환 허용 → 대상 변경 시 목록 재구성 → 카메라·대상 이름 갱신 → 리스폰 TargetRpc → 원래 카메라 복구`

관전 대상은 전환할 때마다 현재 씬의 캐릭터를 기준으로 다시 구성합니다. 직업 교체로 플레이어 오브젝트가 바뀌거나 접속이 종료되어 참조가 사라진 경우에도 유효한 대상으로 인덱스를 보정합니다. 리스폰이 끝나면 오너 클라이언트의 관전 UI와 임시 앵커를 정리하고 카메라를 로컬 캐릭터로 복구합니다.

### 로비 직업 선택

`직업 버튼 선택 → 대기 상태 저장 → 로컬라이징 제목 갱신 → 선택 상태 표시 → 선택 확정 시 플레이어 오브젝트를 통해 서버에 변경 요청`

직업 이름은 `JobType`에서 로컬라이징 키를 만들고, 참조가 없을 때는 enum 이름으로 대체합니다. 선택한 버튼은 다시 누를 수 없도록 상태를 갱신하고, 확정된 값은 로컬 플레이어의 상태 컴포넌트에 전달합니다.

## 파일별 설명

### [`DeathSpectator.cs`](DeathSpectator.cs)

사망 지점과 현재 플레이어를 관전 대상으로 구성하고, 대상 전환 때 목록을 갱신합니다. 리스폰 완료 신호는 `TargetRpc`로 오너 클라이언트에 전달해 UI·임시 앵커·카메라 상태를 복구합니다.

### [`DeathSpectateUIController.cs`](DeathSpectateUIController.cs)

관전 대상 이름을 로컬라이징 인자로 전달하고, 부활까지 남은 시간과 조작 안내의 표시 상태를 관리합니다.

### [`LobbyJobSelectUIController.cs`](LobbyJobSelectUIController.cs)

버튼으로 선택한 직업을 대기 상태로 보관하고 로컬라이징 제목과 버튼 상태를 갱신합니다. 확정된 선택은 로컬 플레이어의 `PlayerAvatarState`를 통해 서버에 요청합니다.
